# Bonnes pratiques : le maillage interne

Un bon maillage interne relie les pages d'un site entre elles de façon
pertinente, avec des textes d'ancrage descriptifs plutôt que génériques
("cliquez ici", "en savoir plus"). Chaque page importante d'un site doit
recevoir au moins un lien interne depuis une autre page — une page qui ne
reçoit aucun lien interne (page orpheline) est difficile à découvrir pour les
moteurs de recherche. Variez les textes d'ancrage pointant vers une même page
pour un maillage plus naturel.
