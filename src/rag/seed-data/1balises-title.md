# Bonnes pratiques : la balise title

La balise title est l'un des signaux les plus importants pour le référencement
on-page. Elle doit contenir entre 30 et 60 caractères pour éviter d'être
tronquée dans les résultats de recherche. Chaque page d'un site doit avoir un
title unique décrivant précisément son contenu. Évitez les caractères de code
(<, >, {, }, [, ]) qui n'ont pas leur place dans un title destiné aux
utilisateurs. Placez le mot-clé principal le plus tôt possible dans le title
pour maximiser sa pertinence perçue par les moteurs de recherche.
