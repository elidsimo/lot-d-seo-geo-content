# Bonnes pratiques : la meta description

La meta description n'est pas un facteur de classement direct, mais elle
influence fortement le taux de clic depuis les résultats de recherche. Une
bonne meta description fait entre 120 et 160 caractères, résume le contenu de
la page de façon engageante, et peut inclure un appel à l'action. Une meta
description manquante ou dupliquée sur plusieurs pages nuit à l'expérience
utilisateur et peut inciter Google à générer automatiquement un extrait moins
pertinent.
