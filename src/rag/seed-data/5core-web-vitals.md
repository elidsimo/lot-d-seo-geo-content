# Bonnes pratiques : les Core Web Vitals

Les Core Web Vitals mesurent l'expérience utilisateur réelle d'une page. Le
LCP (Largest Contentful Paint) doit être inférieur à 2500ms — au-delà de
4000ms, l'expérience est jugée mauvaise par Google. Le CLS (Cumulative Layout
Shift) doit rester sous 0.1 pour éviter les décalages visuels inattendus. Le
INP (Interaction to Next Paint) doit être inférieur à 200ms pour garantir des
interactions fluides. Optimiser ces trois métriques passe souvent par la
réservation d'espace pour les images, l'allègement du JavaScript, et
l'optimisation du temps de réponse serveur.
